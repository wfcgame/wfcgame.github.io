Robot AI Lab brings together my interest in interactive worlds and robotics. The project direction combines **Unity + Robot + ROS 2 + Codex**, with the aim of exploring robot behavior in simulation before connecting that work to physical hardware.

## Project direction

The proposed workflow starts with a small virtual environment: a robot, a destination, and a few obstacles. The goal is to make the robot's observations and actions visible, then use that feedback to guide development.

The intended roles are:

- **Unity:** a virtual environment for visualizing and experimenting with robot behavior.
- **Robot:** physical hardware for a later stage of testing.
- **ROS 2:** the planned communication layer between robot components and simulation.
- **Codex:** assistance with writing, reviewing, and iterating on development code.

## First prototype goals

1. Create a simple virtual robot and a compact test environment.
2. Explore exchanging commands and observations through ROS 2.
3. Visualize movement and obstacle interaction inside the simulation.
4. Evaluate a hardware connection after the simulation workflow is established.

These are project goals, not a list of completed features. Hardware specifications, implementation milestones, and test results will be added as they are documented.
